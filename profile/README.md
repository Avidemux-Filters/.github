## Core Avidemux Features

- **One File at a Time:** Load a video you can already play and see it on a simple timeline.
- **Cut or Copy:** Mark a range to keep, or pass the picture through when you only need a different container.
- **A New Output:** Save under a different name so the source file remains the master.
- **Filters Only When Needed:** A resize or a simple filter is optional. The first save should prove the cut before you add processing.

---

## About Avidemux

Avidemux is a small editor for one video file you already have. People use it to drop the start of a recording, change a container, or make a simpler copy. It is not a multi-track studio, and it is not a way to pull a protected movie off a disc. If the file will not play because it is incomplete or locked, Avidemux will not grant you a clean master.

Work on a copy if this recording is the only one. A save that uses the same name as the source is the easiest way to lose the take you meant to keep. After the new file is written, open it in a normal player and watch the join. A cut that looks fine on the editor's bar can still flash a bad frame at the boundary.

If you need several layers, titles, and a music bed, use a fuller editor. Avidemux earns its place when the job is one file and a clear in and out.

## Getting Started with Avidemux

Prerequisites: One video you may edit, and space for the output.

1. **Open the File:** Confirm the picture moves before you set any marks.
2. **Choose the Range:** Set the start and end of the part you want, or leave the whole file if you are only changing the container.
3. **Set a New Name:** Pick a folder that is not the only copy of the source.
4. **Save and Play:** Watch the new file outside Avidemux. Delete an experiment only after that check.

## Professional & Personal Use Cases

- **A Clean Head:** Remove the countdown or the silence before a talk you recorded.
- **A Simpler Copy:** Put a file you own into a container a picky player will open, without building a full project.
- **A Second Attempt:** Keep the source so a bad cut can be thrown away.
- **A Single Delivery:** Send one checked file, not the editor's project.
